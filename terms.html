4. Backups

Server Saver can create versioned server backups.

Depending on the supported Discord information available to the Bot, a backup may contain:

  • Server name;
  • Server icon;
  • Server banner;
  • Categories;
  • Channels;
  • Roles;
  • Role permissions;
  • @everyone permissions;
  • Permission overwrites;
  • Other server configuration required by supported restoration features.

Server Saver currently retains up to five saved backups per server as part of its versioned backup storage.

Backups are intended to provide administrators with a recovery mechanism following accidental or malicious server changes.

Backup limitations

Backups are not guaranteed to contain every piece of information associated with a Discord server.

In particular, Server Saver does not restore:

  • Message history;
  • Member-specific permission overwrites;
  • Other Discord information that cannot reliably be recreated through the Discord API.

Restoration capabilities may also change if Discord changes its API or permissions.

7. Anti-Nuke Protection

Server Saver uses automated burst and heuristic detection to identify potentially destructive activity.

Depending on the server's configured sensitivity, the Bot may respond to:

  • Channel deletions;
  • Bans;
  • Kicks;
  • Role deletions;
  • Role creations;
  • Dangerous role-permission changes;
  • Dangerous @everyone permission changes;
  • Unwhitelisted bot joins.

Protective actions may include:

  • Removing dangerous permissions from an actor;
  • Kicking an actor;
  • Reverting certain permission changes;
  • Logging the event;
  • Notifying server administrators.

The server owner and users placed on the Server Saver whitelist may be exempt from certain anti-nuke actions.

8. No Guarantee of Complete Protection

Server Saver is a security and moderation tool, not a guarantee of complete server protection.

False positives may also occur, particularly at stricter sensitivity levels.

Server administrators should therefore use additional security measures, including appropriate Discord permissions, two-factor authentication where available, and careful management of users with Administrator permissions.
