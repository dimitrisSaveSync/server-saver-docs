2. Description of Server Saver

Server Saver provides tools intended to help Discord server administrators protect, monitor, and manage their servers.

Features may include:

  • Anti-nuke protection, including detection of mass channel deletions or creations, mass role deletions or creations, mass bans and kicks, dangerous permission escalation, and combined/mixed attack patterns;
  • Configurable automated protective actions (kick, ban, role removal, or quarantine);
  • A permanent blacklist for known hostile users, and a whitelist to exempt trusted administrators;
  • Anti-raid protection, including join-flood detection and automatic or manual server lockdown;
  • JoinGate, including minimum account-age requirements and unauthorized-bot gating on join;
  • Panic Mode, a manually triggered full-server lockdown;
  • Grouped security incident tracking and reporting;
  • Server structure backups, including manual and scheduled automatic backups;
  • Server restoration, including a pre-restoration preview and an automatic safety backup taken before each restoration;
  • Backup export and import, and comparison between saved backups;
  • A configurable, per-server word filter with logging of filtered messages;
  • Moderation commands, including kick, ban, unban, warn, and channel sanitization (message purge via channel recreation);
  • Moderation and security logging;
  • Server configuration and security self-check tools;
  • Administrator and bot whitelisting;
  • Welcome messages;
  • Server status and dashboard information.

Features may be changed, improved, suspended, or removed at any time.

4. Backups

Server Saver can create versioned server backups, either manually or on an automatic schedule configured by a server administrator.

Depending on the supported Discord information available to the Bot, a backup may contain:

  • Server name;
  • Server icon;
  • Server banner;
  • Categories;
  • Channels;
  • Roles;
  • Role permissions;
  • @everyone permissions;
  • Permission overwrites;
  • Other server configuration required by supported restoration features.

Server Saver retains a configurable number of saved backups per server, defaulting to five and adjustable by a server administrator up to a maximum of one hundred. Older backups are only removed after a new backup has been saved successfully.

Backups are intended to provide administrators with a recovery mechanism following accidental or malicious server changes. Administrators may also compare two saved backups to review structural differences between them, without modifying the server.

Backup limitations

Backups are not guaranteed to contain every piece of information associated with a Discord server.

In particular, Server Saver does not restore:

  • Message history;
  • Member-specific permission overwrites;
  • Other Discord information that cannot reliably be recreated through the Discord API.

Restoration capabilities may also change if Discord changes its API or permissions.

5. Backup Export and Import

Server Saver allows administrators to export supported backups as JSON files.

Exported backups may be downloaded, stored externally, or imported into another server where the Bot is installed and the administrator has the required permissions. Imported backups are validated for structure and size before being accepted; malformed or invalid files are rejected.

Administrators are responsible for protecting exported backup files.

Anyone who obtains an exported backup may potentially gain access to the server configuration contained within that file.

Do not upload or share exported backups with people you do not trust.

6. Restoration

The /restore feature allows authorized administrators to restore supported server configuration from a saved backup.

Before performing a restoration, Server Saver presents a preview of the changes a restoration would make, and automatically creates a fresh safety backup of the server's current state. If that safety backup cannot be created successfully, the restoration is not performed. Only one restoration may run at a time for a given server.

Restoration may create, modify, or remove server resources in accordance with the selected backup and the Bot's capabilities. When a restoration finishes, Server Saver reports which operations succeeded and which failed; it does not report a restoration as complete if part of it failed.

You are responsible for reviewing the proposed restoration and ensuring that the selected backup is appropriate.

We do not guarantee that restoration will reproduce the server exactly as it existed when the backup was created, or that every operation within a restoration will succeed.

7. Anti-Nuke Protection

Server Saver uses automated burst detection, heuristic detection, and combined-action scoring to identify potentially destructive activity, including attacks that mix different destructive actions in a way that no single action type alone would reveal.

Depending on the server's configured sensitivity, the Bot may respond to:

  • Channel deletions and creations;
  • Bans;
  • Kicks;
  • Role deletions and creations;
  • Webhook deletions;
  • Dangerous role-permission changes;
  • Dangerous @everyone permission changes;
  • Unwhitelisted bot joins;
  • Actions by users on the Server Saver blacklist, which are treated as an immediate threat regardless of configured sensitivity.

Protective actions may include, depending on the server's configured punishment setting:

  • Removing dangerous permissions from an actor;
  • Kicking, banning, or quarantining an actor;
  • Reverting certain permission changes;
  • Logging the event and grouping related events into a security incident;
  • Notifying server administrators, which may be consolidated into a single summary when many events occur in a short period.

Where the Discord user responsible for a detected permission change cannot be reliably identified from Discord's audit log within a short time, Server Saver will revert the change but will not take punitive action against a specific user for that event.

The server owner and users placed on the Server Saver whitelist are exempt from anti-nuke actions. Server Saver's protective actions against a given user may fail if that user holds a Discord role positioned at or above Server Saver's own role (see Section 3).

8. Anti-Raid Protection

Server Saver can detect an unusually fast rate of new members joining a server and respond by locking the server down, either automatically based on a configurable threshold or manually at an administrator's request.

While a lockdown is active, Server Saver may deny members the ability to send messages or connect to voice channels server-wide. An administrator may also enable an "antijoin" mode in which new members are removed automatically while it remains active.

A lockdown engaged by anti-raid protection and a lockdown engaged through Panic Mode (Section 10) share the same underlying mechanism; disabling one does not reopen the server if the other is still active.

9. JoinGate

Server Saver can restrict who is allowed to remain in a server after joining, based on settings an administrator configures:

  • A minimum Discord account age, below which a new member is removed automatically;
  • Automatic removal of bots that have not been added to the server's bot whitelist.

These checks run at the moment a member joins and rely on information Discord makes available about that account, such as its creation date.

10. Panic Mode and Manual Lockdown

Panic Mode allows an authorized administrator to immediately lock down the entire server, independent of any automated detection. As with anti-raid lockdowns, this may deny members the ability to send messages or connect to voice channels server-wide until an administrator disables it.

11. Blacklist and Whitelist

Administrators may maintain a blacklist of Discord user IDs treated as an immediate threat, and a whitelist of trusted administrators and bots exempt from anti-nuke and join-gating checks. The server owner is exempt automatically. Whitelist and blacklist entries are scoped to the server in which they are configured.

12. Word Filter

Server Saver can automatically delete messages that match a filtered-word list, which may use a default list or a list an administrator has customized for their server. When a message is removed this way, Server Saver posts the removed message's content, author, and channel to the server's configured log channel so administrators can review what was removed.

See Section 3 of our Privacy Policy for more information about how message content is handled in connection with this feature.

13. Security Incident Tracking

Related anti-nuke events detected within a short time of one another may be grouped into a single security incident for reporting purposes, so administrators can review a summarized record of an attack rather than a large number of individual event logs.

14. No Guarantee of Complete Protection

Server Saver is a security and moderation tool, not a guarantee of complete server protection.

Its anti-nuke and anti-raid systems use thresholds, heuristic and burst detection, and combined-action scoring. An attacker who acts slowly enough, or in a way that stays below configured thresholds, may not be detected. Server Saver reacts to activity reported by Discord after it occurs; it cannot prevent a destructive action from being submitted to Discord in the first place.

False positives may also occur, particularly at stricter sensitivity levels.

Server administrators should therefore use additional security measures, including appropriate Discord permissions, correct role hierarchy, two-factor authentication where available, and careful management of users with Administrator permissions.

We are not responsible for damage caused by attacks that Server Saver fails to detect or prevent.
